= kbdgen documentation

kbdgen builds keyboard layouts for Windows, macOS, ChromeOS, iOS and Android
from one `.kbdgen` bundle, and converts layouts to and from CLDR LDML
Keyboard 3.0.

* link:user/kbdgen.html[User guide]: the command line, the bundle and layout
  formats, layout tests, and each target.
* link:dev/kbdgen.html[Developer guide]: the architecture, the build
  pipeline, testing, and each target's generator.

The source is at https://github.com/divvun/kbdgen.
